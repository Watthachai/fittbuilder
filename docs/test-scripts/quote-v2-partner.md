| # | ต้องทำอะไร | เกณฑ์ผ่าน |

| M1 | เปิดใบเสนอราคา **เก่าจริง** บน production ที่สร้างก่อน 13 ส.ค. | ราคา/รายการเดิมครบ · ตารางงวดขึ้น default · ไม่มี error ใน console — **เคสเสี่ยงที่สุดในรอบนี้** |

## วิธีรันซ้ำ

```bash
# 1. Gate เต็ม
npx tsc --noEmit && npm run lint && npx vitest run && npm run build

# 2. เฉพาะโมเดลใบเสนอราคา
npx vitest run lib/__tests__/quote.test.ts lib/__tests__/quote-clauses.test.ts

# 3. API partner lead (ต้องมี dev server)
npm run dev
curl -s -X POST localhost:3000/api/partner-lead -H 'Content-Type: application/json' \
  -d '{"name":"ทดสอบ","company":"บริษัททดสอบ","email":"t@t.co"}'
curl -s -o /dev/null -w '%{http_code}\n' localhost:3000/partner          # ต้องได้ 200
curl -s -o /dev/null -w '%{http_code}\n' localhost:3000/admin/partners   # ต้องได้ 307

# 4. ลบข้อมูลทดสอบเมื่อเสร็จ
psql "$DIRECT_URL" -c "delete from fittbuilder_partner_leads where email like '%@t.co';"
```

> **ระวัง:** `DIRECT_URL` ชี้ไปฐานข้อมูลเดียวกับ production — เขียนอะไรลงไป ผู้ใช้จริงเห็น ลบข้อมูลทดสอบทุกครั้ง
