## T34 · ตัวกลางดึง asset ที่ต้นทางไม่ส่ง header มาให้

**Epic:** E7 — **Type:** Story — **Priority:** High — **Status:** ✅ Done (`cd57e5e` · `64c30de` · `83ea945`)

### ที่มาของปัญหา

พรีวิวถูกเสิร์ฟด้วย **COEP `require-corp`** (ยิง header ของคอนเทนเนอร์จริงมาดูแล้ว) เบราว์เซอร์จึงทิ้งไฟล์ข้าม origin ที่ไม่ส่ง `Cross-Origin-Resource-Policy` และไม่ตอบ CORS ซึ่งครอบคลุมที่ที่คนเอารูปไปวางจริงเกือบทั้งหมด — Figma site, CDN ของเครื่องมือออกแบบ

อาการมองไม่เห็นจากในเดโม: รูปหายไปเฉยๆ ทั้งโมเดลและคนดูจึงไปแก้ที่ markup **หนึ่งเทิร์นจริงถูกใช้ไปกับการเติม `referrerPolicy`, `loading`, `decoding` ให้ทุกเลเยอร์ — และถอด attribute ตัวเดียวที่สำคัญออก**

### สิ่งที่ทำ

`/api/asset` ดึงจากฝั่งเซิร์ฟเวอร์ซึ่งไม่มีข้อจำกัดนั้น แล้วส่งต่อพร้อม header ที่ขาด และเทิร์น build **แก้ URL ที่วัดแล้วว่าโดนบล็อกให้ชี้มาที่นี่เอง** ไม่ได้ฝากเป็นกฎให้โมเดลจำ เพราะโมเดลตรวจ header ไม่ได้

URL ที่ต้นทางส่ง header ครบอยู่แล้วไม่ถูกแตะ — การเอาแบนด์วิดท์เราไปคั่นของที่โหลดได้อยู่แล้วไม่มีประโยชน์กับใคร

### ด่านความปลอดภัย (ทุกด่านรับน้ำหนักจริง)

นี่คือตัวดึงข้อมูลที่ปลายทางมาจากคนนอก ซึ่งคือนิยามของ SSRF:

| ด่าน | กันอะไร |
|---|---|
| ต่อไปที่ **IP ที่ตรวจแล้ว** ไม่ใช่ชื่อโฮสต์ | DNS rebinding — `fetch(url)` resolve ใหม่ตอนต่อ ชื่อที่เพิ่งตอบ IP สาธารณะ ตอบ `169.254.169.254` รอบถัดไปได้ · ชื่อเดินทางไปใน `Host` และ TLS `servername` ใบรับรองจึงยังตรวจกับชื่อ |
| ตาม redirect เองทีละขั้น ตรวจใหม่ทุกขั้น | URL สาธารณะที่ 302 ไปหา metadata endpoint |
| คืนเฉพาะ image/font/audio/video | ไม่ให้โดเมนเราไปรับรอง HTML/JS ของคนอื่น |
| ตัดกลางสตรีมที่ 8 MB · timeout 10 วิ · rate limit | ปลายทางที่ตอบไม่รู้จบ |
| ไม่ส่ง cookie/auth/referer ออก · header ฝั่งตอบสร้างใหม่หมด | ข้อมูลผู้เรียกรั่ว |
| SVG อยู่ใต้ CSP sandbox · ชนิดอื่นไม่ | SVG รันสคริปต์ได้ — แต่ sandbox บนไฟล์ที่รันไม่ได้ วาง response ไว้ใน opaque origin ซึ่งหักล้าง CORS ที่เพิ่งให้ไป |

### บั๊กที่เทสต์กับข้อมูลจริงจับได้

1. **URL ที่เป็นคำนำหน้าของอีกอัน** (`…/a.png` กับ `…/a.png?v=2`) — แทนที่ตัวสั้นก่อนแล้วเหลือหางลอย → เรียงยาวไปสั้น
2. **แทรกงานคั่นระหว่าง `parkDraft(true)` กับ `done`** — สำเนาที่ park ไว้เป็นคนละชุดกับที่เบราว์เซอร์เพิ่งได้ → ย้ายมาก่อน park
3. **`www.w3.org` ถูกนับเป็น asset** — นั่นคือ `xmlns="http://www.w3.org/2000/svg"` ซึ่งเป็น*ชื่อ* namespace ไม่ใช่ไฟล์ ส่งผ่านตัวกลางแล้ว SVG เลิกเป็น SVG · ปัญหาเดียวกันทำให้ `<a href>` ทุกอันกลายเป็น 415 → กรองด้วย `content-type` ที่ปลายทางตอบ

### ⚠️ ความผิดพลาดของผู้ทำ ที่ต้องบันทึกไว้

`2c9d8a4` อ้างว่าพรีวิวใช้ COEP `credentialless` และ `crossOrigin` คือตัวทำให้รูปพัง จึงถอดกฎออกและหด asset check เหลือแค่ฟอนต์ — **ข้ออ้างนั้นวัดมาจากหน้า studio ซึ่งเป็นคนละเอกสารกับที่เดโมรัน**

| หน้า | COEP |
|---|---|
| Studio (`localhost:3000`) | `credentialless` |
| **พรีวิว (`webcontainer-api.io`)** | **`require-corp`** |

บน studio รูป figma ตัวเดียวกันโหลดได้ 3840×2160 โดยไม่ต้องมีอะไรเลย — คำตอบที่มั่นใจมาก และผิดสำหรับที่ที่เดโมรันจริง ย้อนใน `83ea945` และเขียนคำเตือนไว้ทั้งใน prompt และหัวไฟล์ `asset-check.ts`
