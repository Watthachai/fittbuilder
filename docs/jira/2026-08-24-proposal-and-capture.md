## Task 3 — แคปพังแล้วบอกไม่รู้เรื่อง + modal ปิดไม่ได้ + ปุ่มดัชนีหาย

สถานะ: เสร็จ · commit `aafed2a`, `36cce6b`

จากรายงานผู้ใช้ (8 สำเร็จ 6 ไม่สำเร็จ) มี 3 อาการคนละสาเหตุ:

- [x] `[object Event]` — html-to-image reject ด้วย img error Event ไม่ใช่ Error → `why()` ตรวจเองว่ารูปไหนโหลดไม่ขึ้น (`naturalWidth === 0`) หรืออ่านข้ามโดเมนไม่ได้ บอกจำนวน + URL ตัวอย่าง (ยืนยันจากซอร์ส CDN ของไลบรารีจริง สองจุด: `r.onerror = n`, `t.onerror = i`)
- [x] "ปิด modal นี้ไม่ได้" — `CLOSE_LABEL` แมตช์ทั้งป้ายเป๊ะ "ยกเลิกรายการ"/"ปิดหน้าต่าง" เลยไม่ผ่าน → เพิ่มแมตช์ขึ้นต้นด้วยคำปิด (ลำดับหลังตัวชัด) ตัดป้าย destructive ("ยกเลิกและลบ" ไม่ใช่ทางออก) และหาปุ่มปิดนอกกรอบ modal ด้วย (เฉพาะป้ายไม่กำกวม เพราะค้นทั้งหน้า)
- [x] ปุ่ม "เพิ่มดัชนีหน้าจอ" หาย — เงื่อนไข render ซ่อนเมื่อจำนวนประตูครบ ทั้งที่ครบแต่ชี้ผิดก็เป็นได้ → ปุ่มอยู่ตลอด 3 สถานะ: เพิ่มดัชนีหน้าจอ / เติมดัชนีให้ครบ / ตรวจดัชนีอีกครั้ง
- [x] `SHOT_BRIDGE_VERSION` → 21 (ผู้ใช้ต้องรีสตาร์ทพรีวิวหนึ่งครั้ง)
- AC: แคปพังต้องบอกชื่อรูป/สาเหตุ · modal ฟอร์มที่มีปุ่ม "ยกเลิกรายการ" ต้องปิดได้ · ปุ่มดัชนีไม่หายอีก
